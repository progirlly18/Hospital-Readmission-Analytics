# Project report

- `Project_Report.pdf`: the project report (A4), covering Part 1 and Part 2.
- `project_report.html`: its source. The PDF is printed from it with
  Microsoft Edge or Chrome (headless), so images stay linked to the files in
  `docs/` and `screenshots/`:

  ```bash
  msedge --headless=new --no-pdf-header-footer --print-to-pdf=docs/report/Project_Report.pdf docs/report/project_report.html
  ```



All figures in the report come from the repository's documented results
(`docs/part2/`, `artifacts/` outputs on the project machine) and from the
screenshots in `screenshots/`; see `screenshots/part2/README.md` for how the
Part 2 screenshots were captured.
